## Where we are

M0 – M7.6 are merged to `main` and deployed to staging. **M8 is the next and last milestone before the pilot goes live**; it has no brief yet — every previous milestone started from one in [milestones/](milestones/), and M8's row bundles unrelated work (a schema feature, a copy pass, and a production deploy), so it is a candidate for splitting when the brief is written.

Open gates: M7.6's inspection screen has not been walked through signed in — every server round-trip in it (creating a Finding, clearing a damage list, the Accept gate) is verified only by unit test. And M7.5's founder walkthrough — one real case per Stage — is not yet recorded here. `npm run cases:stage` stages exactly that set on the pilot shop for the walk (dev only; see [README](../README.md#staged-cases-for-a-stage-walkthrough)).
