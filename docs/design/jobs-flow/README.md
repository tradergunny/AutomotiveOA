# Jobs flow canvas — working files

Source for the [Jobs Flow Redesign canvas](https://claude.ai/code/artifact/d7794c26-d655-4dbe-ae41-4d9e30237562) (design session 2026-09-02; rulings D-19 – D-25, brief M7.7). `build.mjs` generates the nine `*.dc.html` artboards and `canvas.json` from the tokens in `app/globals.css`; edit the script, run `node build.mjs`, then re-seed and republish the canvas with the `/design` skill's helper. The artboards are the spec for layout and copy weight; the rulings in DESIGN.md are the spec for behavior, and win where the two disagree.
