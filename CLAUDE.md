@AGENTS.md

## Agent skills

### Issue tracker

Issues live in GitHub Issues on `tradergunny/AutomotiveOA`, used through the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The default five labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: the glossary is `CONTEXT.md` at the repo root (never create a `GLOSSARY.md`), and ADRs are `docs/adr/ADR-NNN-<slug>.md`. See `docs/agents/domain.md`.
